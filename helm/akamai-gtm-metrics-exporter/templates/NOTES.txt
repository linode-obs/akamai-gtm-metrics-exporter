Thank you for installing {{ include "akamai-gtm-metrics-exporter.fullname" . }}.

1) Configure GTM domains
------------------------
This chart ships with no domains configured by default:

  config:
    domains: []

You should configure your own for collection of traffic and liveness test data, ex: 
my_values.yaml

  config:
    domains:
      - domain_name: my.super.gtm.domain
        properties:
          - property_name: "myprop"
            dc_nickname:
              - mydc1
              - mydc2
        liveness_tests:
          - property_name: "myprop"
            target_ip: 1.2.3.4

See https://github.com/linode-obs/akamai-gtm-metrics-exporter/blob/master/gtm_metrics_example_config.yml
for more config format information.

2) Create and mount the .edgerc Secret
--------------------------------------
The exporter requires Akamai Edgegrid credentials in order to access the GTM API and collect data about your domains. 
It will run without these credentials but no interesting metrics will be available.

This chart expects a secret with the correct format to pre-exist.
Create a local .edgerc file in this format:

  [{{ .Values.config.edgercSection }}]
  host = akab-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.luna.akamaiapis.net
  client_token = <client_token>
  client_secret = <client_secret>
  access_token = <access_token>

All 4 credentials are available from the Akamai Control Center UI:
Identity and Access Management > Users and API Clients > your_service_account >  Create Credential

Create an opaque Secret from that file:

  kubectl create secret generic my-edgerc-secret \
    --from-file={{ .Values.edgegrid.edgerc.secretKey }}=/path/to/local/.edgerc

Then set the chart to use it:

  helm install {{ .Release.Name }} {{ .Chart.Name }} \
    -n {{ .Release.Namespace }} \
    --set edgegrid.edgerc.existingSecret=my-edgerc-secret \
    -f my_values.yaml
