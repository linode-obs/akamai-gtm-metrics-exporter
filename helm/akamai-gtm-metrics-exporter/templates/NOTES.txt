1) Provide EdgeGrid credentials
------------------------------------------------------
You must supply the exporter with Akamai EdgeGrid credentials.

You can let the chart create a Secret by setting edgegridSecret.create=true and providing host, clientToken, clientSecret, and accessToken:

  helm install {{ .Release.Name }} {{ .Chart.Name }} \
    -n {{ .Release.Namespace }} \
    --set edgegridSecret.create=true \
    --set edgegridSecret.host=akab-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.luna.akamaiapis.net \
    --set edgegridSecret.clientToken=<client_token> \
    --set edgegridSecret.clientSecret=<client_secret> \
    --set edgegridSecret.accessToken=<access_token>

Or you can use an existing Secret:

  kubectl create secret generic my-edgegrid-credentials \
    --from-literal=host=akab-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.luna.akamaiapis.net \
    --from-literal=clientToken=<client_token> \
    --from-literal=clientSecret=<client_secret> \
    --from-literal=accessToken=<access_token>

  helm install {{ .Release.Name }} {{ .Chart.Name }} \
    -n {{ .Release.Namespace }} \
    --set edgegridSecret.name=my-edgegrid-credentials

If your Secret already exists with different key names, set the keyNameRef value, ex:

  helm install {{ .Release.Name }} {{ .Chart.Name }} \
    -n {{ .Release.Namespace }} \
    --set edgegridSecret.name=my-edgegrid-credentials
    --set edgegridSecret.hostRef=my-host-key
    --set edgegridSecret.clientTokenRef=my-client-token-key
    --set edgegridSecret.clientSecretRef=my-client-secret-key
    --set edgegridSecret.accessTokenRef=my-access-token-key

2) Configure GTM domains
------------------------
This chart ships with no domains configured by default:

  config:
    domains: []

You should configure your own for collection of traffic and liveness test data, ex: 
my_values.yaml

  config:
    domains:
      - domain_name: my.super.gtm.domain
        properties:
          - property_name: "myprop"
            dc_nickname:
              - mydc1
              - mydc2
        liveness_tests:
          - property_name: "myprop"
            target_ip: 1.2.3.4

See https://github.com/linode-obs/akamai-gtm-metrics-exporter/blob/master/gtm_metrics_example_config.yml
for more config format information.
