1) Provide EdgeGrid credentials
------------------------------------------------------
The exporter will run without valid Akamai EdgeGrid credentials, but you should supply them for it to be useful.
You must provide all 4 credentials: host, clientToken, clientSecret, and accessToken.

You can let the chart create the Secret:

  helm install {{ .Release.Name }} {{ .Chart.Name }} \
    -n {{ .Release.Namespace }} \
    --set credentials.create=true \
    --set credentials.secretData.host=akab-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.luna.akamaiapis.net \
    --set credentials.secretData.clientToken=<client_token> \
    --set credentials.secretData.clientSecret=<client_secret> \
    --set credentials.secretData.accessToken=<access_token>

Or you can use an existing Secret, but be mindful that the keys are correct:

  kubectl create secret generic my-edgegrid-credentials \
    --from-literal=host=akab-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.luna.akamaiapis.net \
    --from-literal=clientToken=<client_token> \
    --from-literal=clientSecret=<client_secret> \
    --from-literal=accessToken=<access_token>

  helm install {{ .Release.Name }} {{ .Chart.Name }} \
    -n {{ .Release.Namespace }} \
    --set credentials.existingSecret=my-edgegrid-credentials

2) Configure GTM domains
------------------------
This chart ships with no domains configured by default:

  config:
    domains: []

You should configure your own for collection of traffic and liveness test data, ex: 
my_values.yaml

  config:
    domains:
      - domain_name: my.super.gtm.domain
        properties:
          - property_name: "myprop"
            dc_nickname:
              - mydc1
              - mydc2
        liveness_tests:
          - property_name: "myprop"
            target_ip: 1.2.3.4

See https://github.com/linode-obs/akamai-gtm-metrics-exporter/blob/master/gtm_metrics_example_config.yml
for more config format information.
